# Calculadora

Projeto de uma calculadora funcional e responsiva, feita totalmente do zero para praticar lógica e estilização.

Você pode testar a calculadora funcionando direto no navegador através deste link: 
https://andressa-barros.github.io/Calculadora/

## Tecnologias utilizadas
- HTML5
- CSS3 (Grid e Flexbox)
- JavaScript (Vanilla)
